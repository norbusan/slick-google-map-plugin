# Marker icons

The SVG files in this directory were written from scratch for this plugin
and are distributed under the same GPL-2.0-or-later license as the rest of
the plugin. They are simple letter glyphs inside a generic teardrop pin and
contain no third-party artwork.

If you want to swap in a different icon set, just replace the files in this
directory — the plugin resolves names like `restaurant` and
`hotel_0star.png` (legacy alias) to whatever `<name>.svg` is present here.
